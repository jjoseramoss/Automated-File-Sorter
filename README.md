# Python File Organizer CLI

## Status

![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

A command-line interface (CLI) script built in Python to automatically sort and clean a target folder (like "Downloads") by categorizing files into designated directories (e.g., Images, Documents, Code).

---

## 🚀 Key Features

This project demonstrates core competencies in system scripting and file management:

* **100% Automatic Sorting:** Identifies files by extension and moves them into predefined category folders (e.g., Documents, Images, Archives).

* **"Others" Folder Catch-all:** Systematically handles all uncategorized files by moving them into a dedicated "Others" directory.

* **Cross-Platform Pathing:** Utilizes the modern **`pathlib`** module to ensure file operations are robust and work reliably across Windows, macOS, and Linux systems.

---

## 🛠️ Installation & Usage

### 1. Clone the Repository
```bash
git clone [https://github.com/](https://github.com/)[Your-GitHub-Username]/python-file-organizer-cli.git
cd python-file-organizer-cli

```
### 2. Update the path address and run
```bash
command: python organizer.py

type your path address: example -  'c:/Users/jo/Downloads'
```
